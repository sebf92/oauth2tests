Interactive Demo Runner

Runs the full SPIFFE → OAuth2 → Resource Server pipeline live. Each step is executed in real time and the raw JWT claims are shown inline.

{# ── Steps skeleton (shown before run) ──────────────────────────────────────── #}
{# Step 1 #}
Step 1 SPIRE Workload API — Container Attestation

The SPIRE agent verifies this container's OS identity (unix UID selector), checks it against a registered workload entry on the SPIRE server, and issues a short-lived JWT-SVID signed by SPIRE's JWT authority.

{# Step 2 #}
Step 2 SPIFFE Identity

Claims extracted from the SPIRE-issued JWT-SVID. No secret was stored or transmitted — SPIRE verified this container's OS identity before issuing the token.

{# Step 3 #}
Step 3 RFC 7523 Private Key JWT — Keycloak Authentication

The service authenticates to Keycloak using a signed client_assertion JWT (ES256, no client_secret). Keycloak fetches /jwks to verify the signature, then returns an OAuth2 access token.

{# Step 4 #}
Step 4 Resource Server API Call

The OAuth2 access token (obtained via SPIFFE workload identity) is used as a Bearer token to call the protected resource server API.
