Password Grant (ROPC)

Credentials are posted directly to the token endpoint — no browser redirect required.

HTTP Request sent to Keycloak:
POST /realms/demo/protocol/openid-connect/token
Content-Type: application/x-www-form-urlencoded

grant_type=password
&client_id=demo-client
&client_secret=***
&username=alice
&password=***
&scope=openid profile email roles
Security note: ROPC exposes credentials to the client app. Prefer Authorization Code flow in production.
