{# ── Signature explanation ─────────────────────────────────────────────────── #}
Signature — integrity proof

Computed by Keycloak as:
RS256( Base64URL(header) + "." + Base64URL(payload), privateKey )

The Resource Server verifies this using Keycloak's public key fetched from the JWKS endpoint (/realms/demo/protocol/openid-connect/certs). Any modification to the token invalidates the signature.
